## Problem & Solution

기존 모바일 후원 결제 화면은 한 화면에 많은 입력 항목이 집중되어 있어 사용자가 결제 과정의 전체 부담을 크게 느낄 수 있는 구조였습니다.
또한 후원자 유형에 따라 필요한 정보가 달랐지만 모든 사용자에게 동일한 입력 항목이 노출되어 불필요한 입력 과정이 있음을 발견했습니다.

저는 이 과정에서
**"후원 프로세스에서 사용자의 불필요한 이탈을 줄일 수 있지 않을까?"**
라는 문제를 정의하고 해결방안을 제안했습니다.

1. **후원자 유형에 따른 입력 구조 재설계**: 개인·기업·단체 등 후원자 유형에 따라 필요한 정보만
   단계적으로 노출하도록 입력 구조를 재구성했습니다.

2. 한 화면에 과도하게 집중되어 있던 입력 항목을 분석하여 **1단계에는 최소한의 기본 정보만** 남기고, 결제 수단 등의 상세 정보는 2단계로 분리해 인지적 부담을 낮췄습니다.

3. **모바일 환경에 맞춘 UI 개선**: 터치 영역, 입력 필드 간격, 폰트 크기 등을 조정하고
   불필요한 스크롤을 줄여 작은 화면에서도
   결제 과정에 집중할 수 있도록 개선했습니다.

4. **실제 구현 과정까지 관리**: 외부 개발사와 직접 커뮤니케이션하며
   디자인 의도가 실제 서비스에 정확하게 반영되는지 QA하고,
   구현 과정에서 발생한 제약사항에 맞춰 디자인을 조정했습니다.

## 🛠 Challenges & Technical Excellence

### 인지적 부담을 낮추기 위한 단계별 입력 설계

- **단계 간 데이터 연동**: 이전 단계에서 입력한 값이 다음 단계로 자동으로 이어지도록 설계하여, 동일한 정보를 반복 입력해야 하는 번거로움을 없애고 결제 완료까지의 소요 시간을 단축했습니다.
- **용어 표준화 및 직관성 강화**: 혼용되어 사용되던 '납부', '납입' 등의 용어를 통일하여 사용자가 용어 혼선 없이 직관적으로 이해할 수 있도록 개선했습니다.

- **우선순위 기반 정렬**: 사용자가 가장 많이 이용하고 입력 부담이 적은 '신용/체크카드'를 기본 결제 수단으로 배치해 초기 허들을 낮췄습니다.
- **스마트 디폴트 적용**: '후원자 정보와 동일', '기부금 영수증 미신청' 등의 항목을 기본값(Default)으로 설정, 사용자가 추가 입력을 최소화할 수 있도록 설계했습니다.
- **점진적 정보 공개**: 기존에 불필요한 주소값까지 일괄 입력받던 구조를 개선, 사용자가 직접 선택/체크하는 경우에만 추가 입력 영역이 활성화되도록 인터페이스를 최적화했습니다.

### 모바일 환경에 최적화된 인터페이스 구현

- **스크롤 피로도 최소화**: 불필요한 여백과 낭비되는 영역을 과감히 줄여 페이지 전체 길이를 단축, 사용자가 마주하는 정보의 양과 입력에 대한 심리적 압박감을 완화했습니다.
- **중복 정보 및 레이아웃 오류 개선**: 기존 후원 분야 '더보기' 시 불필요하게 넓어지던 영역과 매월 계산 금액이 중복 노출되던 이슈를 해결, 깔끔한 정보 구조로 개편했습니다.
- **시각적 여백의 재조정**: 전체적인 페이지 길이는 줄이되, 텍스트와 UI 요소 간의 간격은 오히려 여유 있게 조정하여 밀집된 느낌을 없애고 쾌적한 가독성을 확보했습니다.
- **터치 인터랙션 최적화**: 작은 화면에서의 터치 실수를 방지하고자 라디오 버튼을 큰 버튼 형태로 변경하고, 입력 필드 간격과 폰트 크기를 모바일 환경에 맞게 최적화했습니다.

### 외부 개발사와의 긴밀한 구현 결과 관리

설계한 UX가 실제 서비스에 안정적으로 적용될 수 있도록 외부 개발사와 직접 소통하며 QA 과정을 관리했습니다. 문서 기반의 상세한 수정 요청서를 통해 결제 단계에서 발생할 수 있는 변수들을 사전에 점검했으며, 구현 과정에서의 기술적 제약 사항을 디자인적으로 보완하며 최종 결과물의 품질을 높였습니다.

## 📊 Results & Lessons Learned

QA 과정에서 발견한 사용자 불편함과 현업의 목소리를 적극적으로 수렴하여, 한 화면에 집중되어 있던 결제 프로세스를 직관적으로 개편했습니다. 그 결과 모바일 후원 성과가 전년 대비 2배 이상 증가하는 뚜렷한 비즈니스 임팩트를 이끌어낼 수 있었습니다.

기존 업무가 유지되는 상황에서 추가적인 리뉴얼을 진행해야 하는 부담도 있었지만, 코로나19 팬데믹 이전에 선제적으로 후원 프로세스를 탄탄하게 정비할 수 있어 시의적절한 프로젝트가 되었습니다. 특히 유관부서와 긴밀히 소통하며 후원 유형별 필수 정보를 새롭게 정의하고 타 부서의 요구사항을 조율하는 소중한 경험을 할 수 있었습니다.

단발성 개선에 그치지 않고 지속적인 성과로 이어져 팀 내외로 UX의 가치를 인정받았으며, 사용자의 문제를 해결하는 일의 즐거움과 깊은 의미를 다시 한번 깨닫게 된 뜻깊은 프로젝트였습니다.
