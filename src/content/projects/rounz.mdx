## 🚀 Key Achievements

인공지능 기반 아이웨어 커머스 플랫폼 라운즈(ROUNZ)에서 노후화된 PHP 기반의 CMS Admin 시스템을 React·TypeScript 스택으로 마이그레이션하고 스타일 충돌 문제를 전면 해결한 프로젝트입니다. 백엔드 중심이라 방치되어 있던 대규모 관리자 사이트의 UI/UX를 주도적으로 개선하고, 사용자 이커머스 서비스의 동적 프로모션 마크업 및 Framer 연동을 함께 담당했습니다.

### 01. CMS Admin 관리자 시스템 리팩토링

#### React, TypeScript, Recoil, MUI, SCSS

- **레거시 스타일 충돌 해결**: 수십 개 페이지에 Bootstrap, MUI, SCSS 등 파편화된 스타일이 꼬여 중복 적용되던 이슈를 발견하고, MUI 공통 컴포넌트 베이스로 통합하여 UI 일관성 확보
- **PHP → React 마이그레이션**: 노후화된 어드민 환경을 현대적인 프론트엔드 스택으로 전면 전환하여 유지보수성 및 시스템 안정성 극대화

#### 파편화된 레거시 스타일 통합 및 어드민 UI 체계 재정립

수십 개의 페이지로 이루어진 대규모 CMS 어드민은 초기 개발 이후 백엔드 개발자 중심 운영으로 UI 관리가 후순위로 밀렸고,
Bootstrap, MUI, SCSS 등 다양한 스타일 체계가 꼬여 중복 적용되는 스타일 충돌 이슈가 심각했습니다.

어드민 특성상 수려한 비주얼보다는 **운영의 효율성과 시스템 안정성**이 최우선이었기에,
UI 에러를 유발하는 **시각적 노이즈 이슈를 찾아내고 제거하는 작업부터** 시작했습니다.

파편화된 UI 사양을 MUI 공통 컴포넌트 베이스로 통일하고, 상세 레이아웃은 SCSS로 분리하여 유지보수성을 극대화했습니다.
또한 관리자의 작업 동선을 분석하여 **불필요한 입력/선택 요소를 정리**하고 데이터 입력 프로세스를 단순화함으로써,
운영 실수를 방지하고 정확도를 높였습니다.

#### JSON 기반 템플릿화로 운영 효율성 극대화

이커머스 특성상 성별, 연령대, 제품군별 순위 데이터 등 대량의 콘텐츠 업데이트가 빈번했으나, 기존에는 매번 반복적인 마크업 수정이 필요했습니다. 이를 **JSON 기반 데이터 구조**로 리팩토링하여 데이터만 교체하면 UI가 자동 렌더링되는 템플릿 시스템을 구축했습니다.
신규 페이지 제작 시 동일한 구조를 즉시 재활용할 수 있게 공유하고, **코드 내 수동 작업으로 인한 오타나 관리 실수를 방지**하여 업무 효율을 향상시켰습니다.

#### Framer를 활용한 고도화된 인터랙션 구현

단순한 상품 나열을 넘어 사용자 참여를 유도하는 인터랙티브 콘텐츠를 구현하기 위해 **Framer와 React 컴포넌트를 연동**했습니다. 디바이스를 감지하여 웹과 앱 링크를 자동으로 분기하는 로직을 포함하고, CMS 및 외부 API와 연동하여 실시간 상품 정보를 자동으로 로드하는 동적 UI를 구축했습니다.

## 📊 Results & Lessons Learned

#### 구조화와 유지보수성의 가치를 체득한 대규모 레거시 개선 경험

우선순위에 밀려 방치되었던 수십 개 페이지의 방대한 레거시에는 파편화된 스타일과 중복 코드 이슈가 있었습니다. 화면상에 눈에 보이는 UI 결함을 바로잡는 것은 물론, 사이드이펙트를 하나씩 통제하며 수많은 파일을 정리해야 했던 과정은 정말 쉽지 않은 도전이었습니다.

단기적인 기능 구현을 넘어, **'처음부터 구조를 탄탄히 짜고 지속적인 리팩토링으로 코드를 관리하는 것'이 서비스의 안정성과 확장성에 얼마나 결정적인지** 온몸으로 깨달았습니다. 당장 눈에 보이지 않더라도 코드 전반의 아키텍처와 모범 사례(Best Practices)를 깊이 고민하게 된 계기가 되었으며, 방대한 기술적 부채를 마주하고 조율해 나가는 과정 속에서 프론트엔드 개발자로서 한 단계 더 단단하게 성장할 수 있었습니다.
