## 🚀 Key Achievements

Chromatic 선물 거래 프로토콜은 Trade, Pools, Reward, Referral 등 다양한 기능이 하나의 서비스 안에서 연결되어 있으며,
특히 Trade 화면은 차트와 포지션 정보, 주문 영역 등 많은 정보를 동시에 다뤄야 했습니다.
복잡한 트레이딩 환경 속에서 기기별 사용 맥락을 고려한 반응형 UI를 선제적으로 설계하고,
React/TypeScript와 Storybook을 기반으로 디자인과 개발 간의 유기적인 협업 시스템을 구축했습니다.

- **UI 개발 100%**: Trade, Pools, Reward, Referral 등 서비스 전반의 페이지와 UI 구현
- **반응형 디자인 80%**: 모바일·태블릿 환경을 고려한 UI 구조 및 화면 설계
- **React 기반 컴포넌트 개발**: 반복되는 UI를 재사용 가능한 컴포넌트로 구조화
- **Storybook 구축**: 공통 컴포넌트를 문서화하고 디자이너, 개발자와 공유
- **선제적 UI 설계**: 디자인 업무가 집중된 시기에 모바일·태블릿 UI를 먼저 설계하고 개발하여 작업 병목을 줄이는 방식 제안

## 🛠 Challenges & Technical Excellence

### 복잡한 트레이딩 UI를 사용자 중심으로 구조화

Trade 화면은 차트와 거래 정보, 주문 영역 등 한 화면에서 확인해야 할 정보가 많기 때문에 화면 크기에 따라 정보의 우선순위를 다르게 구성할 필요가 있었습니다.
Desktop과 Tablet에서는 Short / Long 거래 영역을 함께 확인할 수 있도록 구성하고, Mobile에서는 작은 화면에서도 핵심적인 거래 기능에 집중할 수 있도록 주요 영역을 중심으로 UI를 재구성했습니다.
특히 차트 영역은 화면을 많이 차지하는 요소인 만큼, 필요에 따라 확장하거나 축소할 수 있도록 인터랙션을 고려해 구현했습니다.
단순히 Desktop 화면을 축소하는 방식이 아니라, **화면 크기에 따라 사용자가 실제로 확인해야 하는 정보와 조작 영역을 다시 구성하는 것**에 초점을 맞췄습니다.

### 디자인과 개발 사이의 간극을 줄이는 협업

프로젝트 당시 디자인 작업이 진행되는 동안 퍼블리싱 일정까지 함께 진행해야 했고, 전체 디자인이 완성될 때까지 개발을 기다리면 일정이 지연될 수 있는 상황이었습니다.
이에 디자이너와 협의하여 Mobile과 Tablet 화면을 먼저 설계하고 퍼블리싱을 진행했습니다.
먼저 실제 화면을 구현하면서 반응형 구조와 컴포넌트 구성을 잡고, 이후 디자이너와 함께 세부적인 UI를 조정하는 방식으로 작업했습니다.
이 과정에서 단순히 전달받은 디자인을 구현하는 역할에 머무르지 않고, **구현 과정에서 발견한 문제를 다시 디자인에 반영하며 디자인과 개발을 함께 구체화**할 수 있었습니다.
또한 Storybook을 활용해 공통 UI 컴포넌트를 문서화하고 공유했습니다. 반복적으로 사용되는 UI를 컴포넌트 단위로 관리하면서 디자인과 개발 사이의 커뮤니케이션을 보다 명확하게 만들었습니다.

단순한 마크업에서 더 나아가 React와 TypeScript를 기반으로 UI를 구현하고, Tailwind CSS를 활용해 반응형 스타일을 구성했습니다.
반복적으로 사용되는 UI는 컴포넌트 단위로 분리하고, Storybook을 통해 각 컴포넌트의 상태와 사용 방식을 확인할 수 있도록 구성했습니다.
특히 트레이딩 서비스의 특성상 Desktop과 Mobile의 단순한 크기 변화만으로는 충분하지 않았기 때문에, 화면별 레이아웃과 정보 구조를 함께 고려해 반응형 UI를 구현했습니다.
이를 통해 디자인 결과물을 그대로 옮기는 것을 넘어, **실제 서비스 환경에서 동작하는 UI 구조로 구체화하는 경험**을 쌓았습니다.

## 📊 Results & Lessons Learned

Klaybay에서 시도했던 **선제적 마크업과 React 기반 UI 구현 방식**을 더욱 안정적으로 내재화하여 팀워크를 극대화한 프로젝트입니다.
**Atomic Design 패턴**을 기반으로 재사용 가능한 컴포넌트 구조를 설계하고, **Tailwind CSS**와 **TypeScript**를 엄격하게 적용하여 리소스 효율화와 런타임 안정성을 동시에 확보했습니다.
여기에 **Storybook을 통한 UI 문서화**와 **파일럿 프로젝트 검증**을 더해 팀 전체의 개발 퍼포먼스를 높이는 시스템을 구축했습니다.

협업자의 병목을 해결하기 위해 시작한 노력이 결국 저의 기술적 영역을 확장하고 새로운 성장을 이끄는 강력한 동기부여가 되었으며,
이는 곧 작업의 즐거움으로 이어졌습니다. **'내가 조직에 긍정적인 영향을 주고 있다'는 실감**은 제가 더 몰입하게 만드는 원동력이 되었고,
설계를 넘어 개발 전반을 아우르는 경험을 통해 팀과 개인이 동반 성장하는 협업의 가치를 깊이 체감할 수 있었습니다.

Chromatic 프로젝트를 통해 복잡한 서비스일수록 시각적인 완성도뿐 아니라 **정보의 우선순위와 화면별 사용 맥락을 함께 설계하는 것이 중요하다는 것**을 경험했습니다.
디자인이 완성되기를 기다리기보다 구현 과정에서 발견되는 문제를 피드백하며 함께 구체화해 나갔습니다.
이 프로젝트는 제가 디자인과 개발을 각각 수행하는 것을 넘어, **두 영역을 연결하며 실제 서비스의 사용자 경험을 구현할 수 있다는 것을 보여준 프로젝트**입니다.
