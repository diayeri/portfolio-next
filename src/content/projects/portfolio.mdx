# 🚀 Project Overview

기획부터 디자인, 프론트엔드 개발, 콘텐츠 구조 설계와 배포까지 전 과정을 주도한 개인 포트폴리오 사이트입니다. Next.js와 MDX 기반 아키텍처를 도입하여 유지보수성을 높이고, 커리어와 핵심 기술에 온전히 집중할 수 있는 직관적인 사용자 경험을 구현했습니다.

## 🎨 기획, 디자인 및 AI 협업 프로세스

- **코드 중심 디자인 (Design without Figma):** 별도의 상세 디자인 시안을 먼저 제작하는 대신, 피그마로 전체적인 레이아웃만 가볍게 잡은 뒤 코드로 화면을 직접 구현하며 디자인을 발전시켰습니다. 브라우저에서 실시간으로 결과를 확인하며 디자인과 개발을 하나의 연속된 과정으로 다뤘습니다.
- **AI 기반 개발 보조 (AI-assisted Development):** GPT, Gemini, Copilot 등을 활용해 구현 방법 탐색, 반복적인 코드 작성, UI 아이디어 구체화, 새로운 Next.js 기능 학습 등을 보조받았습니다.
- **주도적인 최종 판단:** AI가 제안한 결과나 기술적 방법론을 프로젝트의 목적과 구조에 맞는지 직접 검증하고 수정하며, 정보 구조, UX/UI 방향, 시각적 컨셉, 기술 선택 등의 최종 결정을 내렸습니다.
- **시각적 정체성 (Visual Identity):** 메인 영역에 Pink(디자인 경험과 시각적 표현), Cyan(실제 구현과 서비스 개발), Purple(두 영역을 연결하는 역할)의 자연스러운 컬러 흐름을 적용하여 경계 없는 확장과 작업 방식을 표현했습니다.
- **핸드메이드 픽셀아트:** 과거 경연대회 대상 수상작이었던 캐릭터 애니메이션을 현재 포트폴리오에 맞게 재구현했습니다. 완성된 에셋 대신 개별 픽셀과 div 요소를 하나씩 배치하며 만드는 과정의 배움과 재미를 담았습니다.

## ⚙️ 아키텍처 및 데이터 구조화

- **CRA에서 Next.js로의 전환 (Migration):** 초기 익숙한 CRA 환경에서 시작했으나, 이미지 처리, 라우팅, 콘텐츠 관리 등 프로젝트가 확장되면서 마주한 한계를 해결하기 위해 Next.js를 직접 학습하고 구조를 전환했습니다.
- **MDX 기반 콘텐츠 아키텍처:** 상세 페이지가 늘어날수록 코드가 복잡해지는 문제를 방지하기 위해 프로젝트 상세 설명과 작업 과정을 MDX로 분리했습니다. Markdown 기반 작성과 React 컴포넌트 활용을 병행하여 UI 구조 수정 없이 콘텐츠 관리 효율성을 높였습니다.
- **타입스크립트 데이터 분리:** 프로젝트 목록 및 공통 정보, 커리어 타임라인 등의 데이터를 TypeScript 파일로 분리하여 관리하고, UI 컴포넌트가 이를 불러와 표현하도록 체계화했습니다.

## 🗂️ 서비스 운영 및 탐색 경험

- **프로젝트 탐색 구조:** 방문자가 작업 범위를 빠르게 파악할 수 있도록 주요 프로젝트는 캐러셀로 먼저 보여주고, 하단에서는 카테고리별 전체 프로젝트 썸네일 탐색 기능을 제공합니다.

* **배포 인프라의 진화 (GitHub Pages → Netlify → Vercel):**
  - 초기에는 가볍게 GitHub Pages를 활용해 배포하려 시도했으나, 프로젝트를 고도화하고 Next.js로 전환하는 과정에서 서버사이드 렌더링(SSR) 및 라우팅 기능을 외부 환경에서 제대로 구동하고 테스트하기 위해 적절한 호스팅 전략이 필요함을 깨달았습니다.
  - 초기에 CRA 환경일 때는 Netlify를 경험해 보았고, Next.js로 마이그레이션한 이후에는 Next.js 프레임워크와 가장 최적의 궁합을 보여주는 Vercel을 도입했습니다. 이를 통해 버전 관리부터 실시간 빌드, 운영 환경까지 배포 파이프라인의 전체 흐름을 깊이 있게 경험했습니다.

## 💡 What I Learned

이 프로젝트를 통해 디자인과 개발을 각각 분리된 역할로 바라보기보다,
하나의 사용자 경험을 완성하기 위한 연속적인 과정으로 바라보게 되었습니다.
직접 디자인하고 바로 구현해보면서 디자인 단계에서 생각하지 못했던 기술적인 제약을 발견하기도 했고,
개발 구조를 이해하면서 디자인 단계에서부터 구현 가능성과 유지보수성을 고려할 수 있었습니다.

또한 AI를 적극적으로 활용하면서
단순히 코드를 직접 작성하는 능력보다, 무엇을 만들 것인지 정의하고 AI가 제안한 결과를 판단하고
필요한 부분을 직접 수정하며 최종적인 서비스를 완성해가는 경험을 했습니다.
