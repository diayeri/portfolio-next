## 🚀 Key Achievements

본 사이트는 서비스의 기획 및 UI/UX 디자인부터 프론트엔드 개발, 배포에 이르는 **웹 프로덕트 개발의 전 과정을 혼자서 주도**하여 완성한 개인 포트폴리오입니다.

특히 이번 프로젝트에서는 **AI 툴을 적극 활용하여 전체적인 아키텍처와 UI 레이아웃을 신속하게 빌드업**했습니다. 오랜 실무를 통해 탄탄하게 다져온 저만의 UI 개발 경험과 전문성이 있었기에, AI가 제안하는 구조를 빠르게 검증하고 의도에 맞게 디테일을 통제하며 개발 속도를 극대화할 수 있었습니다. 이를 통해 화면 구현을 넘어 인프라 배포와 데이터 흐름까지 전체 개발 과정을 완주하며 폭넓은 기술 학습을 이뤄냈습니다.

단순히 결과물을 보여주는 것을 넘어, 최적의 사용자 경험(UX)과 유지보수성을 극대화하기 위해 **Next.js와 TypeScript** 아키텍처를 도입했습니다. 특히 프로젝트 진행 과정에서 발생한 기술적 한계를 분석하고 대안을 찾아 **CRA(Create React App) 환경에서 Next.js로 마이그레이션**을 진행했으며, 콘텐츠 관리의 효율성을 높이기 위해 **MDX** 기반의 아키텍처를 설계·적용했습니다.

- **AI 활용 생산성 극대화 및 UI 전문성 검증 :** AI를 활용해 전체 구조와 UI 뼈대를 빠르게 구성하고, 다년간의 UI 개발 노하우를 바탕으로 이를 정교하게 검증 및 완성
- **기획 및 디자인 100% 주도 :** 정보 구조(IA) 설계부터 와이어프레임, 컴포넌트 디자인, 반응형 UI 구현까지 전 과정 총괄
- **CRA에서 Next.js로의 기술 전환 :** SSR/SSG 이점 확보, 이미지 최적화 및 라우팅/스크롤 동작 등 코어 UX 개선
- **MDX 기반 콘텐츠 아키텍처 :** 반복적인 마크업 작업을 줄이고 마크다운 형식으로 프로젝트 콘텐츠를 유연하게 관리할 수 있는 구조 설계
- **Vercel 기반 CI/CD 파이프라인 :** 지속적인 통합 및 배포 환경을 구축하여 신속한 피드백 루프 및 안정적인 서비스 배포 완성

## 🛠 Challenges & Technical Excellence

### 1. CRA에서 Next.js로의 전환

프로젝트 초기에는 익숙한 **CRA(Create React App)** 환경과 Netlify 배포 조합으로 빠르게 프로토타입을 구축했습니다. 하지만 개발을 진행할수록 포트폴리오 서비스 특유의 한계와 개선 필요성이 명확해졌습니다.

- **SEO 및 초기 로딩 성능 최적화:** CRA의 SPA 구조 특성상 검색엔진 최적화(SEO)와 초기 로딩 속도 측면에서 한계가 존재했습니다. 대외적으로 저를 증명하는 포트폴리오 사이트인 만큼 검색 노출과 성능 최적화가 필수적이었습니다.
- **기본적인 웹 내비게이션 UX 문제:** CRA 환경에서는 페이지 이동 시 스크롤 위치가 유지되거나 상단으로 자연스럽게 복귀하지 않는 등 사소한 UX 결함들이 발생했습니다. 이를 수동으로 제어하기보다 라우팅과 연동된 프레임워크 레벨의 해결책이 필요했습니다.
- **강력한 빌드 타임 최적화 및 이미지 컴포넌트:** 대량의 이미지와 프로젝트 상세 화면을 다룰 때, Next.js가 제공하는 내장 `<Image />` 컴포넌트의 자동 최적화(레이아웃 시프트 방지, WebP 변환 등) 기능이 프로젝트 퀄리티를 높이는 데 결정적이라 판단했습니다.

결과적으로 **Next.js + Vercel** 스택으로 전면 전환하여, 라우팅과 연동된 매끄러운 스크롤 제어, 강력한 성능 최적화, 그리고 안정적인 배포 환경을 동시에 구축할 수 있었습니다.

### 2. MDX를 통한 콘텐츠 관리 시스템 및 유지보수성 향상

포트폴리오의 각 프로젝트 상세 페이지를 구현할 때, 정적 HTML 컴포넌트로 일일이 코드를 작성하는 방식은 새로운 프로젝트를 추가하거나 내용을 수정할 때 엄청난 반복 작업과 유지보수 부채를 유발했습니다.

이를 해결하기 위해 MDX (Markdown + JSX)를 도입했습니다.

- **콘텐츠와 로직의 분리 :** 프로젝트 상세 소개, 트러블슈팅 내용, 이미지 레이아웃 등을 Markdown 형태로 유연하게 작성하고, 필요한 부분만 커스텀 컴포넌트로 확장하여 렌더링할 수 있도록 설계했습니다.
- **개발 생산성 극대화 :** 새로운 프로젝트 이력을 추가할 때 복잡한 JSX 구조를 매번 짜거나 수정할 필요 없이, 깔끔한 문서 형태로 콘텐츠를 관리할 수 있어 운영 효율성이 대폭 향상되었습니다.

### 3. 콘텐츠 집중도를 높인 UI 철학과 픽셀아트 애니메이션

포트폴리오 사이트의 본질은 "방문자가 제 역량과 프로젝트 성과를 얼마나 직관적이고 편안하게 파악할 수 있는가"에 있습니다. 이를 위해 메인 영역은 군더더기를 덜어내고 제 커리어와 주요 기술 스택에 시선이 자연스럽게 집중될 수 있도록 미니멀하고 정돈된 레이아웃으로 설계했습니다.

특히 사이트의 메인 영역을 채우고 있는 **Pink, Cyan Blue, Purple의 컬러 컨셉**은 저의 핵심 역량을 시각적으로 표현하고 있습니다. 감각적인 시각 디자인을 상징하는 **Pink**와 견고한 기술 구현을 뜻하는 **Cyan Blue** 사이에서, 저는 두 영역을 유기적으로 연결하고 조율하는 **Purple**의 면모를 지향합니다. 디자인과 개발 모두를 깊이 이해하며 양쪽을 모두 유기적으로 다룰 수 있는 프론트엔드 개발자라는 정체성을 색채 철학에 녹여냈습니다.

여기에 이러한 아이덴티티를 더 직관적으로 전달하고자 메인 화면에 **직접 픽셀 단위로 색을 채워 만든 아바타 애니메이션**을 구현했습니다.

- **아날로그적 가치와 몰입:** 모든 것이 AI와 자동화 툴로 빠르게 찍혀 나오는 요즘 시대에, `div` 하나하나에 픽셀 좌표와 색상을 부여하며 손수 아바타를 움직이게 만들었던 과정을 담았습니다.
- **수상작의 재해석:** 과거 프론트엔드 부트캠프 당시 애니메이션 경연대회에서 **대상을 수상했던 작품**을 현대적인 웹 환경에 맞춰 재구현한 것으로, 기술적 구현력뿐만 아니라 시각적인 즐거움과 개발을 대하는 저만의 진정성을 함께 전달하고자 했습니다.
