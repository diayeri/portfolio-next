웹 화면을 만들다 보면 요소를 가로로 정렬하거나, 카드 목록을 여러 열로 배치하거나, 화면 크기에 따라 레이아웃을 바꿔야 하는 순간이 자주 찾아옵니다.

CSS에는 이러한 레이아웃을 만들기 위한 다양한 방법이 있습니다. 그중 실무에서 가장 자주 사용하는 방법이 **Flexbox와 Grid**입니다.

처음 배울 때는 `justify-content`, `align-items`, `flex`, `1fr`, `minmax()`처럼 낯선 속성이 많아 헷갈릴 수 있습니다. 하지만 두 레이아웃의 기본 원리를 이해하면 속성을 무작정 외우지 않고도 필요한 상황에 맞게 조합할 수 있습니다.

이 글에서는 Flexbox와 Grid의 차이부터 시작해 핵심 속성, 실무에서 자주 사용하는 패턴, 반응형 레이아웃과 디버깅 방법까지 정리합니다.

## Flex와 Grid, 무엇이 다를까?

가장 먼저 기억할 차이는 **레이아웃을 바라보는 방향**입니다.

- **Flexbox**: 한 방향을 기준으로 요소를 배치하는 1차원 레이아웃
- **Grid**: 행과 열을 함께 설계하는 2차원 레이아웃

Flexbox는 가로 또는 세로 한 방향의 정렬과 공간 분배에 적합합니다. Grid는 행과 열을 함께 고려해 전체적인 배치를 구성할 때 유용합니다.

| 상황                                  | 주로 사용하는 방식 |
| ------------------------------------- | ------------------ |
| 버튼 여러 개를 가로로 배치            | Flexbox            |
| 헤더의 로고와 메뉴 정렬               | Flexbox            |
| 카드 목록을 여러 열로 배치            | Grid               |
| 대시보드의 사이드바와 콘텐츠 영역     | Grid               |
| 카드 내부의 제목과 버튼 정렬          | Flexbox            |
| 전체 페이지 구조와 내부 컴포넌트 배치 | Grid + Flexbox     |

두 방식은 서로 경쟁하는 기술이 아닙니다. 실제 화면에서는 **바깥 구조를 Grid로 만들고, 각 영역 안의 요소를 Flexbox로 정렬하는 식으로 함께 사용**하는 경우가 많습니다.

```css
.page {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr);
  gap: 24px;
}

.card {
  display: flex;
  flex-direction: column;
  gap: 12px;
}
```

여기서 `.page`는 사이드바와 콘텐츠 영역을 나누는 Grid이고, `.card`는 내부 요소를 세로로 쌓는 Flexbox입니다.

## 1-1. Flexbox의 기본 구조

Flexbox는 부모 요소에 `display: flex`를 지정하면서 시작합니다.

```html
<div class="container">
  <div class="item">Item 1</div>
  <div class="item">Item 2</div>
  <div class="item">Item 3</div>
</div>
```

```css
.container {
  display: flex;
}
```

이때 `.container`는 **Flex Container**, 그 안의 자식 요소들은 **Flex Item**이 됩니다.

Flexbox를 이해할 때 중요한 점은 정렬 속성이 단순히 가로와 세로를 의미하지 않는다는 것입니다. Flexbox는 먼저 **주축(Main Axis)**과 **교차축(Cross Axis)**을 정하고, 그 축을 기준으로 배치와 정렬을 계산합니다.

### 주축과 교차축

기본값인 `flex-direction: row`에서는 주축이 가로 방향이고, 교차축은 세로 방향입니다.

```css
.container {
  display: flex;
  flex-direction: row;
}
```

```text
주축(Main Axis) ───────────────→

[ Item 1 ] [ Item 2 ] [ Item 3 ]

            ↑
       교차축(Cross Axis)
```

`flex-direction: column`으로 바꾸면 주축과 교차축도 함께 바뀝니다.

```css
.container {
  display: flex;
  flex-direction: column;
}
```

```text
주축(Main Axis)
      ↓
  [ Item 1 ]
  [ Item 2 ]
  [ Item 3 ]

교차축(Cross Axis) →
```

따라서 `justify-content`는 항상 가로 정렬, `align-items`는 항상 세로 정렬이라고 외우면 안 됩니다.

**`justify-content`는 주축, `align-items`는 교차축을 기준으로 동작합니다.**

### `flex-direction`

아이템이 배치되는 방향을 지정합니다.

| 값               | 설명                      |
| ---------------- | ------------------------- |
| `row`            | 주축을 가로 방향으로 설정 |
| `row-reverse`    | 가로 방향을 반대로 설정   |
| `column`         | 주축을 세로 방향으로 설정 |
| `column-reverse` | 세로 방향을 반대로 설정   |

```css
.container {
  display: flex;
  flex-direction: row;
}
```

`row`가 기본값이므로 가로로 나열하는 경우에는 생략할 수 있습니다.

### `flex-wrap`

아이템이 한 줄에 모두 들어가지 않을 때 줄바꿈할지 결정합니다.

```css
.container {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
```

- `nowrap`: 한 줄을 유지합니다. 기본값입니다.
- `wrap`: 공간이 부족하면 다음 줄로 이동합니다.
- `wrap-reverse`: 줄이 쌓이는 교차축 방향을 반대로 설정합니다.

카드나 태그처럼 공간이 부족할 때 다음 줄로 넘어가야 하는 UI라면 `flex-wrap: wrap`을 사용할 수 있습니다.

### `gap`

아이템 사이의 간격을 지정합니다.

```css
.container {
  display: flex;
  gap: 16px;
}
```

가로와 세로 간격을 다르게 지정할 수도 있습니다.

```css
.container {
  display: flex;
  flex-wrap: wrap;
  column-gap: 24px;
  row-gap: 16px;
}
```

`gap`은 Flexbox와 Grid 모두에서 사용할 수 있으며, 요소마다 `margin`을 주는 방식보다 간격을 관리하기 편리합니다.

## 1-2. Flexbox의 정렬 속성

Flexbox에서 가장 자주 사용하는 속성은 `justify-content`와 `align-items`입니다.

### `justify-content`: 주축 방향 정렬

주축을 기준으로 아이템을 배치합니다.

```css
.container {
  display: flex;
  justify-content: center;
}
```

| 값              | 동작                                                |
| --------------- | --------------------------------------------------- |
| `flex-start`    | 주축의 시작점에 배치                                |
| `flex-end`      | 주축의 끝점에 배치                                  |
| `center`        | 가운데 배치                                         |
| `space-between` | 첫 요소와 마지막 요소를 양 끝에 두고 사이 공간 분배 |
| `space-around`  | 각 요소 주변에 공간 분배                            |
| `space-evenly`  | 요소 사이와 양 끝의 공간을 균등하게 분배            |

실무에서는 `space-between`을 헤더의 로고와 메뉴를 양 끝에 배치할 때 자주 사용합니다.

```css
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```

### `align-items`: 교차축 방향 정렬

교차축을 기준으로 아이템을 정렬합니다.

```css
.container {
  display: flex;
  align-items: center;
}
```

| 값           | 동작                                  |
| ------------ | ------------------------------------- |
| `stretch`    | 아이템을 교차축 방향으로 늘림. 기본값 |
| `flex-start` | 교차축의 시작점에 배치                |
| `flex-end`   | 교차축의 끝점에 배치                  |
| `center`     | 교차축 가운데 배치                    |
| `baseline`   | 텍스트의 기준선을 맞춤                |

예를 들어 헤더 안의 로고와 버튼을 세로 중앙에 맞추려면 다음과 같이 작성합니다.

```css
.header {
  display: flex;
  align-items: center;
}
```

### `align-content`: 여러 줄의 정렬

`align-content`는 아이템 하나하나가 아니라 **여러 줄로 나뉜 Flex Line 전체**를 교차축 방향으로 정렬합니다.

```css
.container {
  display: flex;
  flex-wrap: wrap;
  align-content: center;
}
```

한 줄만 있는 경우에는 정렬할 여러 줄이 없기 때문에 일반적으로 효과가 없습니다. 여러 줄이 있고 컨테이너에 여유 공간이 있을 때 사용합니다.

### `align-items`와 `align-content`의 차이

- `align-items`: 각 줄 안에서 아이템을 정렬
- `align-content`: 여러 줄 전체를 정렬

두 속성은 비슷해 보이지만 정렬하는 대상이 다릅니다.

## 1-3. Flex Item의 크기와 공간 분배

Flexbox가 헷갈리는 가장 큰 이유 중 하나는 아이템의 크기가 단순히 `width`만으로 결정되지 않는다는 점입니다.

Flexbox는 아이템의 기본 크기와 컨테이너의 남는 공간을 고려해 아이템의 크기를 조정합니다.

이때 중요한 속성이 `flex-grow`, `flex-shrink`, `flex-basis`입니다.

### `flex-basis`: 기본 크기

`flex-basis`는 Flexbox가 공간을 분배하기 전에 아이템의 기준으로 삼는 크기입니다.

```css
.item {
  flex-basis: 200px;
}
```

주축이 가로인 경우에는 가로 크기의 기준이 되고, 주축이 세로인 경우에는 세로 크기의 기준이 됩니다.

```css
.container {
  display: flex;
  flex-direction: column;
}

.item {
  flex-basis: 120px;
}
```

위 예시에서 `flex-basis`는 세로 방향의 기준 크기로 사용됩니다.

`flex-basis: auto`는 기본적으로 아이템의 주축 크기 속성(`width` 또는 `height`)을 참고합니다. 해당 크기가 지정되지 않았다면 콘텐츠 크기 등을 바탕으로 기준 크기를 계산합니다.

### `flex-grow`: 남는 공간을 얼마나 나눠 가질까?

`flex-grow`는 컨테이너에 남는 공간이 있을 때 아이템이 그 공간을 얼마나 가져갈지 정합니다.

```css
.item {
  flex-grow: 1;
}
```

예를 들어 세 아이템의 `flex-grow` 값이 모두 `1`이면 남는 공간을 같은 비율로 나눠 가집니다.

```css
.item:nth-child(1) {
  flex-grow: 1;
}

.item:nth-child(2) {
  flex-grow: 2;
}

.item:nth-child(3) {
  flex-grow: 1;
}
```

이 경우 남는 공간은 `1 : 2 : 1`의 비율로 분배됩니다.

주의할 점은 `flex-grow`가 아이템의 전체 크기를 직접 지정하는 속성은 아니라는 것입니다. **기본 크기를 계산한 뒤 남는 공간을 어떻게 분배할지** 결정합니다.

### `flex-shrink`: 공간이 부족하면 얼마나 줄어들까?

`flex-shrink`는 아이템이 한 줄에 들어가지 않을 때 얼마나 줄어들 수 있는지 정합니다.

```css
.item {
  flex-shrink: 1;
}
```

기본값은 `1`입니다. 즉, 공간이 부족하면 아이템이 줄어들 수 있습니다.

```css
.item {
  flex-shrink: 0;
}
```

`0`으로 설정하면 해당 아이템은 Flexbox의 축소 계산에서 줄어들지 않습니다. 다만 이 경우 컨테이너보다 커져 넘칠 수 있으므로 사용 목적을 확인해야 합니다.

### `flex` 단축 속성

실무에서는 `flex-grow`, `flex-shrink`, `flex-basis`를 각각 작성하기보다 `flex` 단축 속성을 자주 사용합니다.

```css
.item {
  flex: 1;
}
```

대표적인 패턴은 다음과 같습니다.

| 선언            | 의미                                                          |
| --------------- | ------------------------------------------------------------- |
| `flex: 1`       | 남는 공간을 분배하며 기본 크기를 0%로 두는 대표적인 확장 패턴 |
| `flex: auto`    | `1 1 auto`와 같은 의미                                        |
| `flex: initial` | `0 1 auto`와 같은 의미                                        |
| `flex: none`    | `0 0 auto`와 같은 의미                                        |

특히 `flex: 1`은 여러 아이템이 동일한 공간을 차지하도록 만들 때 자주 사용합니다.

```css
.container {
  display: flex;
  gap: 16px;
}

.item {
  flex: 1;
}
```

단, `flex: 1`은 아이템의 콘텐츠 크기를 무시하고 무조건 똑같은 너비를 만든다는 뜻은 아닙니다. 콘텐츠의 최소 크기와 Flexbox의 크기 계산 규칙에 따라 예상과 다른 결과가 나올 수 있습니다.

## 1-4. Flexbox 실전 패턴

### 패턴 1. 헤더 양 끝 정렬

```html
<header class="header">
  <a class="logo" href="/">Logo</a>
  <nav class="nav">...</nav>
  <button class="menu-button">Menu</button>
</header>
```

```css
.header {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 24px;
}
```

로고와 메뉴, 버튼을 하나의 행에 배치하고 양 끝으로 분리합니다.

### 패턴 2. 버튼을 오른쪽으로 밀기

```css
.actions {
  display: flex;
  align-items: center;
  gap: 8px;
}

.actions .primary {
  margin-left: auto;
}
```

`margin-left: auto`는 남는 공간을 왼쪽 마진으로 가져갑니다. 주축이 가로인 Flexbox에서는 마지막 버튼을 오른쪽으로 밀 때 유용합니다.

### 패턴 3. 세로로 쌓고 하단 버튼 고정

```css
.card {
  display: flex;
  flex-direction: column;
  min-height: 320px;
}

.card__button {
  margin-top: auto;
}
```

카드 내부를 세로로 배치한 뒤 버튼에 `margin-top: auto`를 주면 남는 공간을 위쪽 마진으로 가져가 버튼을 아래쪽에 배치할 수 있습니다.

### 패턴 4. 콘텐츠가 넘치지 않도록 하기

Flex Item은 기본적으로 콘텐츠의 최소 크기보다 작아지지 않으려는 특성이 있습니다. 긴 텍스트나 넓은 테이블 때문에 레이아웃이 밀리는 경우가 있습니다.

```css
.layout {
  display: flex;
}

.main {
  flex: 1;
  min-width: 0;
}
```

`min-width: 0`은 아이템이 콘텐츠의 최소 너비에 묶이지 않고 더 작아질 수 있도록 허용합니다.

특히 Flexbox 안에서 긴 텍스트, 코드, 테이블이 영역을 밀어내는 경우 확인해 볼 속성입니다.

## 2-1. CSS Grid의 기본 구조

Grid는 행과 열을 함께 정의해 요소를 배치하는 레이아웃입니다.

```css
.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 16px;
}
```

위 코드는 동일한 너비의 열 세 개를 만듭니다.

Flexbox와 마찬가지로 부모 요소가 **Grid Container**, 자식 요소가 **Grid Item**이 됩니다.

Grid를 이해하려면 다음 개념을 알아두면 좋습니다.

- **Grid Line**: 행과 열을 구분하는 선
- **Grid Track**: 두 Grid Line 사이의 행 또는 열
- **Grid Cell**: 행과 열이 만나는 하나의 셀
- **Grid Area**: 하나 이상의 셀로 이루어진 영역

```text
Grid Line
  ↓
┌─────────┬─────────┬─────────┐
│ Cell    │ Cell    │ Cell    │
├─────────┼─────────┼─────────┤
│ Cell    │ Cell    │ Cell    │
└─────────┴─────────┴─────────┘
```

## 2-2. Grid의 핵심 속성

### `grid-template-columns`

열의 개수와 크기를 정의합니다.

```css
.container {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;
}
```

위 예시는 첫 번째 열을 `200px`로 고정하고 나머지 두 열이 남는 공간을 나눠 갖도록 합니다.

### `grid-template-rows`

행의 크기를 정의합니다.

```css
.container {
  display: grid;
  grid-template-rows: 100px 1fr auto;
}
```

행의 크기를 고정값, 비율, 콘텐츠 크기 등으로 설정할 수 있습니다.

### `fr` 단위

`fr`은 Grid 컨테이너에서 사용할 수 있는 남은 공간을 비율로 나누는 단위입니다.

```css
.container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
}
```

남는 공간을 `1 : 2 : 1`로 분배합니다.

`fr`은 단순히 전체 너비의 비율만 의미하는 것은 아닙니다. 고정 크기와 간격 등을 제외한 공간을 분배하며, 각 트랙의 최소 크기 조건도 함께 고려합니다.

### `repeat()`

반복되는 트랙을 간결하게 작성합니다.

```css
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
```

위 코드는 다음과 같은 의미입니다.

```css
.container {
  grid-template-columns: 1fr 1fr 1fr;
}
```

### `gap`

행과 열 사이의 간격을 지정합니다.

```css
.container {
  display: grid;
  gap: 24px;
}
```

행과 열의 간격을 다르게 설정할 수도 있습니다.

```css
.container {
  display: grid;
  row-gap: 32px;
  column-gap: 24px;
}
```

## 2-3. Grid의 배치와 정렬

### `grid-column`과 `grid-row`

Grid Item이 차지할 열과 행의 범위를 지정합니다.

```css
.item {
  grid-column: 1 / 3;
}
```

이는 첫 번째 Grid Line에서 세 번째 Grid Line까지 차지한다는 의미입니다. 따라서 두 개의 열을 차지합니다.

```css
.item {
  grid-column: span 2;
}
```

`span 2`는 현재 배치 위치에서 두 개의 트랙을 차지하도록 합니다.

행도 같은 방식으로 지정할 수 있습니다.

```css
.item {
  grid-row: 1 / 3;
}
```

### `grid-template-areas`

영역 이름을 사용해 레이아웃을 시각적으로 정의할 수 있습니다.

```css
.layout {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr);
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  gap: 16px;
}

.header {
  grid-area: header;
}

.sidebar {
  grid-area: sidebar;
}

.main {
  grid-area: main;
}

.footer {
  grid-area: footer;
}
```

영역을 문자열로 표현하기 때문에 전체 구조를 한눈에 파악하기 쉽습니다.

### `justify-items`와 `align-items`

Grid Container 안에서 각 Grid Item을 셀 기준으로 정렬합니다.

- `justify-items`: 각 셀 안에서 가로 방향 정렬
- `align-items`: 각 셀 안에서 세로 방향 정렬

```css
.container {
  display: grid;
  justify-items: center;
  align-items: center;
}
```

### `justify-content`와 `align-content`

Grid 전체 트랙이 컨테이너보다 작을 때 Grid 자체를 정렬합니다.

- `justify-content`: Grid 전체를 가로 방향으로 정렬
- `align-content`: Grid 전체를 세로 방향으로 정렬

**`items`는 각 아이템을, `content`는 Grid 전체를 정렬한다**고 구분하면 이해하기 쉽습니다.

## 2-4. 반응형 Grid: `minmax()`, `auto-fit`, `auto-fill`

Grid는 반응형 카드 레이아웃을 만들 때 특히 유용합니다.

### `minmax()`: 최소 크기와 최대 크기

`minmax()`는 트랙이 가질 수 있는 최소 크기와 최대 크기를 지정합니다.

```css
.container {
  display: grid;
  grid-template-columns: repeat(3, minmax(200px, 1fr));
  gap: 16px;
}
```

각 열은 최소 `200px`을 유지하고, 남는 공간을 나눠 가집니다.

다만 이 코드는 화면이 좁아져 세 열의 최소 크기를 유지할 수 없으면 넘칠 수 있습니다. 열 개수를 자동으로 조정하고 싶다면 `auto-fit` 또는 `auto-fill`과 함께 사용할 수 있습니다.

### `auto-fit`으로 카드 개수 자동 조정

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 240px), 1fr));
  gap: 24px;
}
```

이 패턴은 컨테이너 너비에 따라 들어갈 수 있는 카드 개수를 자동으로 조정합니다.

- 공간이 넓으면 여러 열로 배치
- 공간이 좁아지면 열 개수를 줄임
- 카드의 최소 너비는 가능한 범위에서 유지
- 남는 공간은 카드가 나눠 가짐

`min(100%, 240px)`을 사용하면 컨테이너가 `240px`보다 좁은 경우에도 최소 너비 때문에 카드가 바깥으로 넘치는 상황을 줄일 수 있습니다.

### `auto-fit`과 `auto-fill`의 차이

두 속성 모두 반복 가능한 열을 자동으로 생성하지만, 남는 공간을 처리하는 방식에 차이가 있습니다.

- `auto-fill`: 들어갈 수 있는 트랙을 유지하며 빈 트랙도 남겨둡니다.
- `auto-fit`: 빈 트랙을 접고 실제 콘텐츠가 있는 트랙이 남는 공간을 사용할 수 있도록 합니다.

카드가 적을 때도 일정한 열 구조를 유지하고 싶다면 `auto-fill`, 카드가 컨테이너 너비를 넓게 채우도록 하고 싶다면 `auto-fit`을 고려할 수 있습니다.

## 2-5. Grid 실전 패턴

### 패턴 1. 카드 목록

```css
.cards {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 24px;
}
```

화면 크기에 따라 열 개수를 바꾸고 싶다면 미디어 쿼리를 사용할 수 있습니다.

```css
.cards {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 24px;
}

@media (max-width: 900px) {
  .cards {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
}

@media (max-width: 600px) {
  .cards {
    grid-template-columns: 1fr;
  }
}
```

### 패턴 2. 사이드바와 메인 콘텐츠

```css
.layout {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr);
  gap: 24px;
}
```

사이드바는 고정 너비를 유지하고, 메인 콘텐츠는 남는 공간을 사용합니다.

`minmax(0, 1fr)`은 메인 영역이 콘텐츠의 최소 너비 때문에 불필요하게 커지는 상황을 방지하는 데 도움이 됩니다.

### 패턴 3. 특정 카드만 넓게 배치

```css
.cards {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 16px;
}

.card--featured {
  grid-column: span 2;
}
```

특정 카드가 두 열을 차지하도록 만들 수 있습니다. 다만 콘텐츠 순서와 배치가 자연스럽게 이어지는지 확인해야 합니다.

## 3-1. Flexbox와 Grid를 함께 사용하기

실무에서는 한 가지 레이아웃 방식만 고집할 필요가 없습니다.

예를 들어 상품 목록 페이지를 만든다고 가정해보겠습니다.

- 전체 페이지의 사이드바와 상품 영역: Grid
- 상품 카드 목록: Grid
- 상품 카드 안의 이미지, 제목, 가격, 버튼: Flexbox
- 카드 안의 버튼 그룹: Flexbox

```css
.product-page {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr);
  gap: 32px;
}

.product-list {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 24px;
}

.product-card {
  display: flex;
  flex-direction: column;
  gap: 12px;
}

.product-card__actions {
  display: flex;
  gap: 8px;
  margin-top: auto;
}
```

전체적인 구조와 반복되는 열 배치는 Grid로, 각 컴포넌트 내부의 정렬과 공간 분배는 Flexbox로 구성한 예시입니다.

## 3-2. 자주 발생하는 문제와 디버깅

### Flex Item이 줄어들지 않고 영역을 밀어낼 때

Flex Item은 기본적으로 콘텐츠의 최소 크기를 고려합니다. 긴 텍스트나 테이블이 영역을 밀어내는 경우 다음 속성을 확인합니다.

```css
.main {
  min-width: 0;
}
```

필요하다면 내부 콘텐츠에도 줄바꿈이나 넘침 처리를 적용해야 합니다.

```css
.text {
  overflow-wrap: anywhere;
}
```

### Grid 열이 예상보다 넓어질 때

`1fr`을 사용했는데도 열이 줄어들지 않는다면 콘텐츠의 최소 크기가 영향을 주고 있을 수 있습니다.

```css
.layout {
  grid-template-columns: 240px minmax(0, 1fr);
}
```

또는 각 열에 최소 크기를 명시할 수 있습니다.

```css
.cards {
  grid-template-columns: repeat(3, minmax(0, 1fr));
}
```

### `align-items: center`가 적용되지 않을 때

정렬할 공간이 충분하지 않으면 가운데 정렬이 눈에 띄지 않을 수 있습니다. 컨테이너의 크기와 방향, 정렬 축을 함께 확인합니다.

```css
.container {
  display: flex;
  align-items: center;
  min-height: 200px;
}
```

### `align-content`가 동작하지 않을 때

`align-content`는 여러 줄 또는 트랙 전체를 정렬할 때 사용합니다. Flexbox에서는 여러 줄이 만들어져야 하고, Grid에서는 트랙 전체를 정렬할 여유 공간이 있어야 효과를 확인할 수 있습니다.

## 3-3. 레이아웃을 선택하는 기준

속성을 외우기 전에 어떤 문제를 해결해야 하는지 먼저 생각하면 선택이 쉬워집니다.

### Flexbox를 선택하기 좋은 경우

- 한 방향으로 요소를 정렬할 때
- 요소 사이의 공간을 유동적으로 나눌 때
- 콘텐츠의 길이에 따라 요소 크기가 달라져야 할 때
- 버튼, 내비게이션, 카드 내부처럼 컴포넌트 단위의 정렬이 필요할 때

### Grid를 선택하기 좋은 경우

- 행과 열을 함께 설계해야 할 때
- 카드 목록처럼 반복되는 열 구조가 필요할 때
- 사이드바와 메인 콘텐츠 등 페이지의 큰 구조를 나눌 때
- 특정 아이템이 여러 행이나 열을 차지해야 할 때

### 함께 사용하기 좋은 경우

- 전체 페이지는 Grid로 구성하고 내부 요소는 Flexbox로 정렬
- 대시보드의 위젯 영역은 Grid, 위젯 내부 버튼과 텍스트는 Flexbox
- 상품 목록은 Grid, 상품 카드의 콘텐츠와 액션 영역은 Flexbox

## 마무리

Flexbox와 Grid는 복잡한 CSS 속성의 모음이라기보다, **공간을 어떻게 나누고 요소를 어떻게 배치할 것인지에 대한 서로 다른 레이아웃 모델**입니다.

Flexbox는 주축을 중심으로 요소를 배치하고 공간을 분배합니다. Grid는 행과 열을 함께 정의해 더 큰 구조를 만듭니다.

처음에는 두 방식의 속성을 모두 외우기보다, 다음 세 가지를 먼저 판단해보면 좋습니다.

1. 요소를 한 방향으로 배치하는가, 행과 열을 함께 설계하는가?
2. 남는 공간을 아이템이 나눠 가져야 하는가?
3. 화면 크기가 바뀌었을 때 요소의 개수와 배치를 어떻게 바꿀 것인가?

이 기준을 가지고 작은 UI부터 직접 만들어보면 Flexbox와 Grid를 상황에 맞게 선택하는 감각을 익힐 수 있습니다.
